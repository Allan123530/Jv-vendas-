# 🎨 PIXBOX

Plataforma moderna de catálogos digitais para vendedores.

**"Seu catálogo. Seus produtos. Seu espaço."**

## ✨ Recursos

- ✨ Autenticação segura com Supabase
- 📦 Gerenciamento de produtos
- 💰 Controle de vendas e ganhos
- 🎯 Sistema de metas
- 🔥 Produtos em destaque
- 📱 Design responsivo (Mobile-First)
- 🛒 Carrinho e checkout
- 💳 Estrutura pronta para pagamentos

## 🚀 Como começar

1. Clone o repositório
2. Instale as dependências: `npm install`
3. Configure as variáveis de ambiente em `.env.local`
4. Execute: `npm run dev`
5. Abra http://localhost:3000

## 📚 Stack

- **Frontend**: Next.js 14, React 18, TailwindCSS
- **Backend**: Supabase (PostgreSQL + Auth + Storage)
- **UI**: Lucide React Icons, Framer Motion
- **Forms**: React Hook Form + Zod
- **State**: Zustand

## 🔐 Segurança

- Row Level Security (RLS) no banco de dados
- Autenticação segura
- Validação de formulários
- Proteção de rotas administrativas
